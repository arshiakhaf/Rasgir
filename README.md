# رأس‌گیر چک — Rasgir

ابزار آفلاین محاسبه و تنظیم چک بر پایه «رأس وزنی» (تقویم شمسی، فقط اعداد صحیح،
بدون ممیز شناور) + ابزار مدیریت مجوز وابسته به دستگاه.

دو بخش اصلی:

- **`app` — رأس‌گیر چک** (`ir.rasgir.check`)؛ برای حسابدار/اپراتور.
- **`manager` — مدیر مجوز** (`ir.rasgir.manager`)؛ ابزار جداگانه صدور مجوز با کلید صادرکننده.

## بسته تحویلی

| فایل | توضیح |
|---|---|
| `dist/rasgir-check-1.0.0.apk` | برنامه اپراتور — امضاشده با کلید release |
| `dist/rasgir-manager-1.0.0.apk` | مدیر مجوز — امضاشده با همان کلید |
| `deliverables/keys/` | **خارج از گیت**: keystore + رمز، بسته کلید صادرکننده و رمز آن (تحویل امن) |
| `corelib/` | هسته دقیق (Jalali، Rational، موتور رأس، پیش‌پرداخت، مجوز) + تست‌ها |
| `tests/jvm/` | ۴۱۴ تست (report در `test-report.txt`) |

## ساخت بدون شبکه (همین محیط)

ساخت امضاشده با ابزار کاملاً آفلاین (kotlinc → d8 → aapt2 → zipalign → apksigner):

```bash
tools/offline-build/build.sh app    dist/rasgir-check-1.0.0.apk
tools/offline-build/build.sh manager dist/rasgir-manager-1.0.0.apk
```

اجرای تست‌های JVM هسته:

```bash
tools/offline-build/run-tests.sh
```

## ساخت با Android Studio (نیازمند اینترنت برای وابستگی‌ها)

ساختار Gradle استاندارد است (`settings.gradle.kts` شامل `:corelib`، `:app`، `:manager`).
باز کردن ریشه پروژه در Android Studio و اجرای `assembleRelease` کافی است.

## فعال‌سازی (قفل دستگاه)

- برنامه اپراتور در اولین اجرا یک کلید EC در Android Keystore می‌سازد (غیرقابل کپی).
- کد درخواست `RGREQ…` را به مدیر مجوز می‌فرستید.
- مدیر با کلید خصوصی صادرکننده (که فقط نزد صاحب برنامه است) مجوز می‌سازد.
- مجوز فقط روی همان دستگاه (همان هش کلید عمومی) معتبر است.

## یادداشت امنیتی

رمزها/کلیدها در `deliverables/keys/` **در گیت نیستند** و عمداً gitignore شده‌اند؛
این پوشه به‌صورت دستی/بایگانی تحویل می‌شود. به رمزهای داخل آن مانند رمز‌عبور رفتار کنید.
